# WeatherApp
This app displays an interactive map where your current location is marked with a user location marker. This marker updates dynamically as your GPS location changes.
You can long-press anywhere on the map to place a marker at that point, showing the city name, latitude and longitude of the selected location. Upon confirming the selected location, you will be redirected to a weather feedback page for that area.

# Additional Features
Displays external weather data from online-meteo.com sources.
Provide weather forecasts.
